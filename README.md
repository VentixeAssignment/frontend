# Ventixe
This was an assignment in a course for CloudServices (Azure) where I used microservices. The Azure functions etc are no longer active due to costs so unfortunately this application is not working out of the box.

The goal was to create a MVP web application using Azure web app/Azure function app and also gRPC.
In the application you can show/create events and users can book an event. 
Also when a user signs up, an email should be sent with a verification code.

In the assignment there were also a Figma design as a template for my MVP where we had to make a decision on which parts of the design were the most important for a first demo.
